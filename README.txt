МОГАЙ ОНЛАЙН — запуск

1. Создай репозиторий на GitHub и загрузи 4 файла из архива в корень.
2. На render.com создай New > Web Service, подключи репозиторий.
3. Runtime: Node; Build command: npm install; Start command: npm start.
4. Дождись Deploy и открой HTTPS-ссылку Render в Chrome.
5. Нажми «Создать», отправь другу ссылку и код комнаты.
6. Друг открывает ссылку и нажимает «Войти».

Работает: комнаты до 12 игроков, отображение перемещений, ников и HP.
Ограничение: зомби, боссы, удары и монеты пока локальные у каждого игрока; синхронизация общего боя требует дополнительной разработки.
При засыпании бесплатного сервера Render первое подключение может быть медленным.
